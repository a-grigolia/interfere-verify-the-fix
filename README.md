# Verify the Fix

A clickable concept for [Interfere](https://interfere.com), by Avto Grigolia.

I think Interfere is a really cool product. I wish I'd had something like it while working at Locale, and that's why I'm applying.

## What I'm assuming

All I know about Interfere is that it catches bugs and fixes them on the spot. I worked from the public docs and a recorded demo, not the product itself, so the rest is a guess:

- Nobody owns the step between "the agent wrote a fix" and "the customer is unblocked."
- A fix can go to a preview before it ships.
- I don't know what the Needs attention column covers. The idea doesn't depend on it.
- All the data here is made up.

## The idea

The agent finds the bug and writes the fix. Before it goes to engineering, someone who doesn't read code checks that it works: a customer service agent, a PM, a designer.

1. **Inbox.** A problem shows up marked Ready to verify.
2. **Problem.** They watch the few seconds where the customer hit the bug.
3. **Verify.** They repeat what the customer did on a preview with the fix, and mark it Fixed or Still broken.
4. **Engineer review.** The engineer gets the code with that check attached, and merges.
